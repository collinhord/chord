# Steam Deck OLED 1TB - Buyer's Guide

## Hardware Overview
- **Steam Deck OLED 1TB** - Main gaming console
- **Valve USB-C Power Adapter** - Official charging cable
- **Carrying Case** - Protective travel case
- **JSAUX 6-in-1 Docking Station** - Includes M.2 SSD enclosure + HDMI cable
- **PS5 Controller** - Wireless gaming controller with USB-A charger

## Pre-Installed Software

### Core Gaming Platform
- **Steam OS** - Valve's gaming-optimized Linux distribution
- **Dozens of pre-installed games** - Ready to play immediately

### Essential Modifications
- **Decky Loader** - Plugin manager for Steam Deck customization
  - Enables community plugins for enhanced functionality
  - Access via Quick Access menu (⋯ button)

### Emulation Suite
- **EmuDeck** - All-in-one retro gaming solution
  - Pre-configured emulators for multiple console generations
  - ROMs folder located in `/home/deck/Emulation/roms/`
  - Launch games through Steam interface or EmulationStation DE

### Utility Software
- **ProtonTricks** - Windows game compatibility tool
  - Manages Proton prefixes for individual games
- **Bottles** - Windows application compatibility layer
  - Run Windows software in isolated environments

## Quick Start Guide

1. **Power On**: Hold power button for 3 seconds
2. **Gaming**: Launch games from Steam interface or desktop mode
3. **Docking**: Connect JSAUX dock for TV/monitor gaming
4. **PS5 Controller**: Pair via Bluetooth in Settings > Controller
5. **Emulation**: Access retro games through "Emulation" collection in Steam

## Important Notes
- System is pre-configured - avoid reinstalling EmuDeck unless necessary
- Decky plugins accessible via Quick Access menu during gameplay
- Switch between Gaming Mode (default) and Desktop Mode via power menu
- Optional Steam profile transfer available with 30+ additional games
